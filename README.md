# ClipES

把西语 AI 科普视频变成一个能问答的知识库——提问即答,带时间戳出处,点开直接跳到视频对应时刻。
Convierte vídeos de divulgación de IA en español en una base de conocimiento consultable: pregunta y obtén respuesta, con fuente y minuto exacto, con enlace directo a ese momento del vídeo.

**📖 [中文说明](README.zh.md) ｜ [Documentación en Español](README.es.md)**

---

这是 [VideoListo](https://github.com/Lnnkun/VideoListo) 和 [VideoBusca](https://github.com/Lnnkun/VideoBusca) 两个学习项目的整合收尾:把"转录+生成简介"和"检索+RAG问答"两条分开的流水线,合并成一个有前端、有后端、能真正跑起来的完整产品。
Es la integración final de dos proyectos de aprendizaje, [VideoListo](https://github.com/Lnnkun/VideoListo) y [VideoBusca](https://github.com/Lnnkun/VideoBusca): une "transcripción + generación de metadatos" y "búsqueda + respuesta RAG" en un único producto completo, con frontend y backend funcionando de verdad.
